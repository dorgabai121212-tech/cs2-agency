# סוכנות CS2 — צוות שיווק של עובדי AI לערוץ שלך

**סוכנות CS2** היא תוכנה שרצה על המחשב שלך ומתנהגת כמו סוכנות שיווק קטנה עבור ערוץ
Counter-Strike 2. אתה מעלה קליפ, והצוות עושה את השאר:

1. צופה בקליפ ומבין מה יש בו (אייס? קלאץ'? רגע מצחיק?)
2. חותך גרסאות לכל רשת: סרטון רחב ליוטיוב, וגרסה אנכית קצרה לשורטס, טיקטוק ורילס
3. כותב כותרות, תיאורים, תגיות והאשטגים בעברית (ובאנגלית לפי הצורך)
4. מחליט באילו רשתות לפרסם ומתי
5. **מחכה לאישור שלך**, ורק אז מעלה
6. מציע רעיונות לקידום, מנסח תגובות לצופים, עוקב אחרי צפיות ומנהל את התקציב

הכול נשלט ממקום אחד: **לוח בקרה בדפדפן** (בעברית) או **שורת פקודה** (`agency`).

> **חשוב:** כברירת מחדל הסוכנות עובדת ב**מצב ניסיון** (`dry_run: true`). במצב הזה שום דבר
> לא עולה באמת לרשתות. הצוות רק מראה מה *היה* עושה. כך אפשר להתנסות בבטחה.

## המבנה הארגוני: מי עושה מה

בראש הסוכנות עומד **מנכ"ל אחד**. הוא מנהל את כל העובדים, מדבר איתך ומדווח לך.
**אתה הבעלים.** רק אתה מאשר פרסום, הוצאת כסף ותגובות לצופים. המנכ"ל לא יכול לאשר שום
דבר בעצמו, וזה נאכף בקוד ולא רק בהוראות.

```
                         ┌───────────────┐
                         │  אתה (הבעלים)  │   מאשר / דוחה
                         └───────┬───────┘
                                 │
                         ┌───────▼───────┐
                         │    המנכ"ל      │   מנהל את הצוות, תדריך יומי, צ'אט איתך
                         └───────┬───────┘
     ┌────────┬────────┬────────┼────────┬────────┬────────┬────────┬────────┐
     │        │        │        │        │        │        │        │        │
 אנליסט    עורך    קופירייטר  אסטרטג   מפרסם    מקדם    מנהל     אנליסט   מנהל
 וידאו     וידאו              תוכן                       קהילה    נתונים   כספים
```

| עובד | שם באנגלית | מה הוא עושה |
|---|---|---|
| **המנכ"ל** | `manager` | הבוס היחיד. מפעיל את כל התהליך על כל סרטון חדש, כותב לך תדריך יומי ועונה לך בצ'אט. יכול להזיז מועדים ולבקש הצעות קידום, אבל **לא יכול לאשר** כלום. |
| **אנליסט וידאו** | `analyst` | צופה בקליפ (דוגם תמונות ממנו) ומזהה את סוג הקליפ (אייס, קלאץ', מצחיק, הדרכה...), המפה, הנשקים, הרגעים החזקים, החלון הכי טוב לשורט, וגם נותן לו ציון. |
| **עורך וידאו** | `editor` | מכין גרסה רחבה (16:9) ליוטיוב, פייסבוק ו-X, גרסה אנכית (9:16) של עד 60 שניות לשורטס, טיקטוק ורילס, ותמונה ממוזערת (thumbnail). |
| **קופירייטר** | `copywriter` | כותב כותרת, תיאור, תגיות והאשטגים לכל רשת, ושומר על מגבלות האורך של כל אחת (למשל X עד 280 תווים, כותרת יוטיוב עד 100). |
| **אסטרטג תוכן** | `strategist` | מחליט באילו רשתות לפרסם ובאיזו שעה, לפי אזור הזמן שלך, ומסביר למה. למשל: הדרכה תעלה קודם ליוטיוב, וקליפ מצחיק לטיקטוק ולשורטס. |
| **מפרסם** | `publisher` | מעלה בפועל לרשתות, אחרי שאישרת. במצב ניסיון הוא רק מדווח. אם העלאה נכשלת, הוא מסמן "נכשל" ומציג את השגיאה, ולעולם לא מדווח על הצלחה מזויפת. |
| **מקדם** | `promoter` | מציע קידום אורגני: הודעה לדיסקורד שלך, פוסט לקהילות רדיט שבחרת, ותגובה נעוצה. הוא יכול גם להציע קידום ממומן, אבל רק כבקשת הוצאה שמחכה לאישורך. |
| **מנהל קהילה** | `community` | קורא תגובות של צופים ומנסח תשובות. כל תשובה מחכה לאישורך (כברירת מחדל). |
| **אנליסט נתונים** | `analytics` | מושך צפיות, לייקים ותגובות מהרשתות, ומסיק מה הרשת הכי טובה, באיזו שעה כדאי לפרסם ואיזה סוג קליפ מצליח. |
| **מנהל כספים (CFO)** | `finance` | עוקב אחרי הוצאות והכנסות (AdSense, טיקטוק, חסויות), שומר על התקציב החודשי ועל תקרת ההוצאה הבודדת, ומפיק דוח חודשי בעברית. |

## התקנה ב-Windows, צעד אחר צעד

### שלב 1: להתקין Python

1. נכנסים לאתר https://www.python.org/downloads/ ומורידים את הגרסה האחרונה (3.10 ומעלה).
2. מריצים את קובץ ההתקנה.
3. **חשוב מאוד:** במסך הראשון מסמנים את התיבה **"Add python.exe to PATH"**, ורק אז לוחצים Install Now.

### שלב 2: להתקין ffmpeg (מומלץ מאוד)

ffmpeg הוא הכלי שבעזרתו העורך חותך את הגרסאות האנכיות ויוצר תמונות ממוזערות.
בלעדיו הסוכנות עדיין עובדת, אבל כל הרשתות יקבלו את הסרטון המקורי כמו שהוא.

הדרך הקלה: פותחים **PowerShell** (תפריט התחל, מקלידים PowerShell) ומריצים:

```powershell
winget install Gyan.FFmpeg
```

אחרי ההתקנה **סוגרים את PowerShell ופותחים אותו מחדש.**

### שלב 3: להוריד את הסוכנות

אם קיבלת קובץ ZIP, מחלצים אותו לתיקייה פשוטה, למשל `C:\cs2-agency`.
(אם יש לך git: `git clone <כתובת המאגר> C:\cs2-agency`.)

### שלב 4: להריץ את ההתקנה

1. פותחים PowerShell.
2. נכנסים לתיקייה:
   ```powershell
   cd C:\cs2-agency
   ```
3. מריצים:
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\install.ps1
   ```

> **למה `-ExecutionPolicy Bypass`?** כברירת מחדל, Windows חוסם הרצה של סקריפטים שהורדו
> מהאינטרנט. הפקודה הזו מתירה את ההרצה **רק לפעם הזו** ולא משנה שום הגדרה במחשב.
> אם אתה מעדיף לאפשר סקריפטים מקומיים לתמיד (למשתמש שלך בלבד):
> `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`

סקריפט ההתקנה עושה את כל זה לבד:
- בודק ש-Python מותקן ושהגרסה מתאימה
- בודק אם ffmpeg קיים (ואם לא, מסביר איך להתקין)
- יוצר סביבה וירטואלית בתיקייה `.venv`, כדי לא ללכלך את המחשב
- מתקין את כל הספריות, כולל אלה שנדרשות לרשתות החברתיות
- מריץ `agency init`, שיוצר את `config.yaml`, את `.env` ואת תיקיית `data`
- שואל אם להפעיל את לוח הבקרה כבר עכשיו

### שלב 5: להפעיל בכל פעם מחדש

בכל פעם שרוצים לעבוד עם הסוכנות:

```powershell
cd C:\cs2-agency
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

הדפדפן ייפתח לבד בכתובת **http://127.0.0.1:8765**. כדי לעצור, לוחצים **Ctrl+C** בחלון
ה-PowerShell. כל עוד החלון פתוח, המתזמן פועל ומפרסם בזמן שנקבע.

> רוצה להשתמש בפקודות `agency` ישירות ב-PowerShell? קודם מפעילים את הסביבה:
> `.\.venv\Scripts\Activate.ps1`. אפשר גם להריץ בלי להפעיל:
> `.\.venv\Scripts\agency.exe status`
>
> אם מריצים `agency` מתיקייה אחרת, הסוכנות משתמשת אוטומטית בתיקיית ההתקנה (C:\cs2-agency)
> כשיש בה `config.yaml`. הפקודה `agency status` מדפיסה באיזו תיקייה ובאיזה מסד נתונים היא עובדת.

## השגת מפתח API של Anthropic (המוח של הצוות)

הצוות "חושב" בעזרת Claude. בלי מפתח הסוכנות עובדת ב**מצב הדגמה**: כל השלבים רצים, אבל
התשובות קבועות ולא באמת מותאמות לקליפ שלך. זה טוב לניסיון, לא לעבודה אמיתית.

1. נכנסים ל-https://console.anthropic.com ונרשמים או מתחברים.
2. בתפריט **Billing** מוסיפים אמצעי תשלום וקונים קרדיט. השימוש ב-API **בתשלום**, לפי
   כמות. כדאי להגדיר שם גם **מגבלת הוצאה חודשית**.
3. בתפריט **API Keys** לוחצים **Create Key**, נותנים שם (למשל `cs2-agency`) ומעתיקים את המפתח.
   הוא מתחיל ב-`sk-ant-`. **המפתח מוצג פעם אחת בלבד.**
4. פותחים את הקובץ `.env` שבתיקיית הסוכנות בעזרת Notepad:
   ```powershell
   notepad .env
   ```
5. מדביקים את המפתח בשורה:
   ```
   ANTHROPIC_API_KEY=sk-ant-...המפתח שלך...
   ```
6. שומרים וסוגרים, ואז מפעילים מחדש את `start.ps1`.

> **אל תשתף את הקובץ `.env` עם אף אחד** ואל תעלה אותו ל-GitHub. הוא מכיל את כל הסודות שלך.
> הסוכנות לא כותבת את הסודות ללוגים, למסד הנתונים או להודעות ל-Claude.

> **שים לב:** העלות של Claude היא חיוב ישיר שלך מול Anthropic, ולא עוברת דרך תקציב הקידום של
> הסוכנות. אפשר להוריד עלויות על ידי שינוי `llm.effort` ל-`low` בקובץ `config.yaml`.

## הפעלה ראשונה במצב ניסיון

1. פותחים את `config.yaml` (עם Notepad) וממלאים את פרטי הערוץ:
   ```yaml
   channel:
     name: "השם של הערוץ שלך"
     language: "he"
     handle: "@your_handle"
   ```
2. מוודאים שמופיע `dry_run: true` (זו ברירת המחדל).
3. מפעילים את `start.ps1`.
4. בלוח הבקרה תראה:
   - **מבנה ארגוני**: המנכ"ל למעלה, ומתחתיו העובדים עם המצב החי של כל אחד (פנוי / עובד / שגיאה)
   - **העלאת סרטון**: גוררים קובץ לתיבה
   - **תור אישורים**: כפתורים גדולים של אישור ודחייה
   - **סרטונים ופוסטים**: טבלה עם המצב של כל סרטון ופוסט
   - **כספים**: פס תקציב, הוצאות, הכנסות ורווח נקי
   - **יומן פעילות**: מה כל עובד עשה ומתי
   - **צ'אט עם המנכ"ל**: אפשר לשאול אותו כל דבר בעברית
   - **פלטפורמות**: אילו רשתות פעילות ואילו מוגדרות
5. העלה קליפ קצר לניסיון, אשר אותו וראה מה הצוות "היה" מפרסם.

אפשר גם לבדוק את המצב משורת הפקודה:

```powershell
.\.venv\Scripts\agency.exe status
.\.venv\Scripts\agency.exe platforms
```

## העלאת סרטון

### מלוח הבקרה

גוררים קובץ (MP4, MOV, MKV, WEBM או AVI) לתיבת ההעלאה. אפשר לכתוב גם **רמז לכותרת**, למשל
"אייס עם AWP בדאסט 2". הצוות יתחיל לעבוד, ואת ההתקדמות רואים ביומן הפעילות ובכרטיסי העובדים.

### משורת הפקודה

```powershell
.\.venv\Scripts\agency.exe upload "C:\Videos\ace_mirage.mp4" --title "אייס בפתיחה במירז'"
```

הסרטון מועתק לתיקייה `data\videos`, והצוות עובר עליו: ניתוח, עריכה, כתיבה ותכנון.
בסוף תקבל טבלה עם **תוכנית הפרסום** (באיזו רשת, איזו כותרת, מתי ולמה) ו**מספר אישור**.

## אישור או דחייה

במצב `publishing.mode: approve` (ברירת המחדל), כל תוכנית פרסום מחכה לך.

**בלוח הבקרה:** בתור האישורים לוחצים **אשר** או **דחה**. אפשר להוסיף הערה.

**בשורת הפקודה:**

```powershell
.\.venv\Scripts\agency.exe approvals              # מה מחכה לי?
.\.venv\Scripts\agency.exe approve 3              # לאשר את בקשה מספר 3 (תתפרסם בזמן שתוכנן)
.\.venv\Scripts\agency.exe approve 3 --now        # לאשר ולפרסם מיד (גם ביוטיוב: ציבורי עכשיו, בלי תזמון)
.\.venv\Scripts\agency.exe reject 3 --note "הכותרת לא טובה"
.\.venv\Scripts\agency.exe approvals --all        # כולל בקשות שכבר הוחלטו
```

יש שלושה סוגי בקשות:

| סוג | מה זה | מה קורה אחרי אישור |
|---|---|---|
| **פרסום** (`publish`) | תוכנית העלאה לכל הרשתות של סרטון אחד | הפוסטים מתוזמנים (או עולים מיד עם `--now`) |
| **הוצאה** (`spend`) | הצעה לקידום ממומן, עם סכום בשקלים | מנהל הכספים בודק תקרות, רושם את ההוצאה, ונותן לך **הוראות צעד אחר צעד** לביצוע ידני |
| **תגובה** (`reply`) | תשובה לתגובה של צופה | התשובה נשלחת לרשת |

> **הסוכנות לעולם לא מוציאה כסף בעצמה.** היא לא מתחברת למערכות פרסום ממומן. אחרי שאישרת הוצאה
> היא נותנת לך הוראות, ואתה זה שמבצע את הקידום בפועל, באתר של הרשת.

אם בחרת `publishing.mode: auto`, תוכניות הפרסום מתוזמנות בלי לחכות לך. הוצאות כסף ותגובות לצופים
**תמיד** ממתינות לאישור, בכל מצב.

## תקציב וכספים

ב-`config.yaml`:

```yaml
finance:
  currency: "ILS"
  monthly_budget_ils: 200      # תקציב קידום חודשי בשקלים
  max_single_spend_ils: 50     # הסכום המקסימלי להוצאה בודדת
```

- כברירת מחדל שני הסכומים הם **0**, כלומר אין הוצאות בכלל.
- הוצאה שחורגת מהתקציב החודשי או מהתקרה הבודדת **נדחית גם אם אישרת אותה.** זו רשת ביטחון כפולה.

פקודות שימושיות:

```powershell
.\.venv\Scripts\agency.exe budget                                   # מצב התקציב החודש
.\.venv\Scripts\agency.exe expense 50 ads "קידום טיקטוק לקליפ האייס"  # רישום הוצאה ששילמת
.\.venv\Scripts\agency.exe income 320 adsense "תשלום AdSense ספטמבר"  # רישום הכנסה
.\.venv\Scripts\agency.exe income 500 sponsorship "חסות של חנות ציוד"
.\.venv\Scripts\agency.exe report                                   # דוח חודשי בעברית
.\.venv\Scripts\agency.exe report --month 2026-09                   # דוח לחודש מסוים
```

את ההכנסות (AdSense, קרן היוצרים של טיקטוק, חסויות) **רושמים ידנית**, מלוח הבקרה או מהפקודות
למעלה, כי הסוכנות לא מתחברת לחשבון הבנק או לחשבונות התשלום שלך.

## מעבר לפרסום אמיתי, רשת אחר רשת

**לא צריך להפעיל הכול בבת אחת.** מומלץ להתחיל ברשת אחת (למשל יוטיוב), לוודא שהכול עובד ורק
אז להוסיף את הבאה.

### הצעדים

1. **מגדירים את הרשת:** עוקבים אחרי המדריך המפורט [docs/PLATFORMS_SETUP.md](docs/PLATFORMS_SETUP.md)
   ומדביקים את המפתחות בקובץ `.env`.
2. **מוודאים שהרשת מוגדרת:**
   ```powershell
   .\.venv\Scripts\agency.exe platforms
   ```
   בעמודת "מפתחות API" צריך להופיע **מוגדר**. אם מופיע "חסר", מוצגים שמות המפתחות שחסרים.
3. **מכבים ב-`config.yaml` רשתות שעוד לא הגדרת**, כדי שהאסטרטג לא יתכנן אליהן:
   ```yaml
   publishing:
     platforms:
       youtube: {enabled: true}
       youtube_shorts: {enabled: true}
       tiktok: {enabled: false}
       instagram_reels: {enabled: false}
       facebook: {enabled: false}
       x: {enabled: false}
   ```
4. **מעבירים את מצב הניסיון לכבוי:**
   ```yaml
   dry_run: false
   ```
5. מפעילים מחדש את `start.ps1`. מעכשיו פוסטים מאושרים עולים באמת.

> **מצב ניסיון הוא מתג אחד לכל הסוכנות.** כשהוא כבוי, כל רשת שמופעלת (`enabled: true`)
> **ומוגדרת** תפרסם באמת. רשת מופעלת שחסרים לה מפתחות תיכשל עם הודעה ברורה, ולא תפרסם.
> לכן מכבים מראש כל רשת שעוד לא מוכנה.

### הערות לכל רשת

| רשת | מה חשוב לדעת |
|---|---|
| **יוטיוב / שורטס** | בהעלאה הראשונה ייפתח דפדפן לאישור הגישה לחשבון גוגל שלך. האסימון נשמר ב-`data\youtube_token.json`. **מכסת ה-API היומית** שגוגל נותנת כברירת מחדל (10,000 יחידות) מספיקה לבערך **6 העלאות ביום**, כי כל העלאה עולה כ-1,600 יחידות. שורטס = סרטון אנכי של עד 60 שניות עם `#Shorts`. |
| **טיקטוק** | **אפליקציה שעוד לא עברה ביקורת (audit) של טיקטוק יכולה לפרסם רק כפרטי** (`SELF_ONLY`: רק אתה רואה). אחרי שהביקורת עברה, מוסיפים ב-`config.yaml`: `tiktok: {enabled: true, privacy_level: PUBLIC_TO_EVERYONE}` |
| **אינסטגרם רילס** | נדרש חשבון **מקצועי** (עסקי או יוצר) שמקושר ל**עמוד פייסבוק**. |
| **פייסבוק** | מפרסם לעמוד (Page), לא לפרופיל אישי. |
| **X (טוויטר)** | נדרשת גישת **Read and Write**. לגישת ה-API של X יש מגבלות ולפעמים גם עלות. בדוק את התנאים העדכניים אצלם. |
| **רדיט** | מפרסם **רק** לקהילות שרשמת ב-`config.yaml`: `reddit: {enabled: true, subreddits: ["GlobalOffensive"]}`. קרא את החוקים של כל קהילה לפני כן. רוב הקהילות לא אוהבות קידום עצמי מוגזם. |
| **דיסקורד** | הודעה לערוץ בשרת שלך דרך Webhook. קובץ נשלח רק אם הוא קטן מ-25MB, ואחרת נשלח קישור בלבד. |

## שגרה יומית מומלצת

1. **בבוקר:** מפעילים את `start.ps1` וקוראים את **התדריך היומי** של המנכ"ל:
   ```powershell
   .\.venv\Scripts\agency.exe brief
   ```
2. **מעלים את הקליפים של אתמול**, אחד אחד או כמה ביחד.
3. **עוברים על תור האישורים:** בודקים כותרות, שעות ורשתות. מאשרים מה שטוב ודוחים עם הערה מה
   שלא, כי ההערות עוזרות לצוות להשתפר.
4. **עוברים על התגובות שהמנהל קהילה ניסח**, ומאשרים את מה שמתאים.
5. **פעם ביום או פעמיים בשבוע:** מושכים נתונים ותובנות:
   ```powershell
   .\.venv\Scripts\agency.exe analytics
   ```
6. **בסוף החודש:** רושמים את ההכנסות (AdSense, חסויות) ומפיקים דוח: `agency report`.
7. **משאירים את החלון של `start.ps1` פתוח**, כדי שהמתזמן יפרסם בזמן. אם המחשב כבוי, הפוסטים
   יעלו כשתפעיל אותו שוב. אפשר גם להריץ ידנית `agency tick`.

בכל רגע אפשר פשוט לשאול את המנכ"ל בצ'אט: *"מה מחכה לי היום?"*, *"איזה סרטון הצליח השבוע?"*,
*"תזיז את הטיקטוק של מחר לשמונה בערב"*.

## כללי בטיחות (חשוב!)

אלה כללי ברזל, והם **נאכפים בקוד** ולא רק "מבוקשים" מה-AI:

1. **כסף לא זז בלי אישור שלך.** כל פעולה שעולה כסף הופכת לבקשת אישור. גם אחרי אישור, חריגה
   מהתקציב החודשי או מתקרת ההוצאה הבודדת **נדחית**. הסוכנות לא מתחברת למערכות פרסום ממומן
   ולא מבצעת תשלומים בעצמה.
2. **מצב ניסיון כברירת מחדל.** שום דבר לא עולה באמת עד שתשנה ל-`dry_run: false`.
3. **אישור לפני פרסום** (במצב `approve`, ברירת המחדל).
4. **אין מעורבות מזויפת.** אין בוטים, אין קניית צפיות, לייקים או עוקבים, אין ספאם ואין
   הצבעות מזויפות. אלה פשוט לא קיימים בתוכנה. דברים כאלה גם מסכנים את הערוץ שלך בחסימה.
5. **כבוד לתנאי השימוש (ToS) של כל רשת** ולמגבלות הקצב שלה. רדיט ודיסקורד מקבלים פרסומים
   **רק** במקומות שרשמת בעצמך בהגדרות.
6. **הסודות נשמרים רק ב-`.env`**: לא ב-`config.yaml`, לא בלוגים, לא במסד הנתונים ולא בהודעות ל-Claude.
7. **כנות:** אם העלאה נכשלה, תראה "נכשל" עם השגיאה. הסוכנות לא מדווחת על הצלחה שלא קרתה.
8. **לוח הבקרה פתוח רק למחשב שלך** (`127.0.0.1`). אין בו סיסמה, ולכן לא כדאי לפתוח אותו לרשת.

תזכורות נוספות:
- **טיקטוק:** כל עוד האפליקציה שלך לא עברה ביקורת, הפוסטים יעלו כפרטיים.
- **יוטיוב:** בערך 6 העלאות ביום במכסה הרגילה. אם צריך יותר, אפשר לבקש מגוגל הגדלת מכסה.
- אתה האחראי על התוכן שמתפרסם בשמך. תקרא את מה שאתה מאשר.

## שאלות נפוצות

**אני חייב מפתח של Anthropic?**
לא כדי לנסות. בלי מפתח הסוכנות עובדת במצב הדגמה עם תשובות קבועות. לעבודה אמיתית צריך מפתח.

**כמה זה עולה?**
התוכנה עצמה חינמית. אתה משלם ל-Anthropic על השימוש ב-Claude, לפי כמות. מחיר קליפ בודד תלוי
באורך שלו וברמת המאמץ (`llm.effort`). מומלץ להגדיר מגבלת הוצאה ב-console.anthropic.com.
החיבור לרשתות עצמו חינמי ברוב המקרים. X עשויה לגבות על גישת API.

**לוח הבקרה לא נפתח.**
ודא שחלון ה-PowerShell של `start.ps1` עדיין פתוח ואין בו שגיאה אדומה. נסה לפתוח ידנית את
http://127.0.0.1:8765. אם הפורט תפוס, שנה את `dashboard.port` ב-`config.yaml`.

**כתוב "python is not recognized".**
Python לא נוסף ל-PATH. התקן אותו מחדש וסמן **"Add python.exe to PATH"**, ואז פתח PowerShell חדש.

**כתוב "running scripts is disabled on this system".**
זו מדיניות ההרצה של Windows. הרץ עם `powershell -ExecutionPolicy Bypass -File .\start.ps1`
(ראה שלב 4 בהתקנה).

**העורך לא חתך גרסה אנכית.**
כנראה ש-ffmpeg לא מותקן או שלא פתחת PowerShell חדש אחרי ההתקנה. בדוק עם `ffmpeg -version`.

**הפוסט בטיקטוק פרטי, למה?**
כי האפליקציה שלך בטיקטוק עוד לא עברה ביקורת. ראה [docs/PLATFORMS_SETUP.md](docs/PLATFORMS_SETUP.md).

**יוטיוב מחזיר שגיאת quota.**
עברת את המכסה היומית (בערך 6 העלאות). המכסה מתאפסת בחצות לפי שעון האוקיינוס השקט. פוסט שנכשל
מסומן "נכשל". אחרי שהמכסה מתאפסת לוחצים **נסה שוב** ליד הפוסט בלוח הבקרה, או מריצים
`agency retry מספר-הפוסט`. לא צריך להעלות את הסרטון מחדש ולא צריך אישור חדש.

**סגרתי את החלון (או שהמחשב נכבה) באמצע העלאה. מה עכשיו?**
פוסט שנשאר "בהעלאה" יותר משעתיים מסומן אוטומטית "נכשל" עם הסבר. בדוק ברשת אם הסרטון בכל זאת
עלה. אם לא, הרץ `agency retry מספר-הפוסט`. אישור שנקטע באמצע הביצוע מופיע ב-`agency approvals`
ובלוח הבקרה עם הכפתור **המשך ביצוע**, או שממשיכים עם `agency approve מספר`.

**טיקטוק כתב "still processing".**
טיקטוק לא אישר בזמן שהפוסט עלה, ולכן הוא מסומן "נכשל" ולא "פורסם". פתח את אפליקציית טיקטוק ובדוק.
רק אם הסרטון לא שם, הרץ `agency retry` (אחרת יעלה פעמיים).

**שיניתי את config.yaml ועכשיו יש שגיאה.**
הסוכנות מראה באיזו שורה הבעיה. בדרך כלל זו מרכאה שלא נסגרה, או רווחים/Tab בהזחה, או מילה במקום
מספר (למשל `port: abc`).

**אפשר לפתוח את לוח הבקרה מהטלפון?**
אם תגדיר `dashboard: {host: "0.0.0.0"}`, לוח הבקרה נפתח לרשת הביתית. הכניסה אפשרית רק עם קישור
סודי (`?key=...`) שמודפס בחלון בכל הפעלה. אל תשתף אותו, ואל תעשה את זה ברשת ציבורית.

**איך אני מוחק את כל הנתונים ומתחיל מחדש?**
סגור את הסוכנות ומחק את התיקייה `data`. ההגדרות (`config.yaml`) והסודות (`.env`) נשארים.
אם שמרת שם את `client_secret.json` של יוטיוב, העבר אותו קודם למקום אחר.

**המנכ"ל יכול לאשר פרסום בעצמו?**
לא. אין לו כלי כזה. רק אתה מאשר, מלוח הבקרה או מהפקודה `agency approve`.

**אפשר להריץ את זה על שרת או על מחשב אחר בבית?**
אפשר, אבל לוח הבקרה בלי סיסמה. השאר אותו על `127.0.0.1`, אלא אם אתה יודע מה אתה עושה.

**איפה הקבצים שלי?**
הסרטונים והגרסאות נשמרים ב-`data\videos`. מסד הנתונים (פוסטים, אישורים, כספים) נמצא בתיקייה `data`.
