# חיבור הפלטפורמות: המדריך המלא

**הדרך הקלה היא האשף בלוח הבקרה:** אייקון התקע (**חיבורים**) ← לוחצים על אריח הפלטפורמה ← עוקבים אחרי
הצעדים. כל אשף מקשר לפרק המתאים בקובץ הזה. הקובץ הוא הגרסה הארוכה, עם כל הלחיצות.

**כמה כללים לפני שמתחילים:**
- **כבר יש לך סטודיו?** מתחילים בכרטיס **"ייבוא מהסטודיו"** בלוח הבקרה (או `agency import`).
  הוא לוקח את מזהי פייסבוק ואינסטגרם ואת החיבורים שכבר שמורים במחשב. אחרי מעבר מחשב החשבונות עדיין
  מחוברים אצל הפלטפורמות, וצריך רק להדביק מחדש: מפתח Zernio (פרק 1), מפתח עמוד של מטא (פרק 2) ומפתח בוט
  בטלגרם (פרק 3).
- **איפה המפתחות נשמרים:** מה שמדביקים באשף נשמר בכספת של Windows (Credential Manager, תחת `cs2-agency`).
  אם אין כספת, הוא נשמר בקובץ `.env` בתיקיית הסוכנות. הסוכנות **רק קוראת** את המפתחות של הסטודיו הישן
  (`cs2studio`) ואף פעם לא משנה אותם.
- **מפתח לא מדביקים בשום מקום אחר:** לא בצ'אט (גם לא עם Claude), לא בטלגרם ולא בצילום מסך. אם מפתח דלף,
  מבטלים אותו באתר של הפלטפורמה ויוצרים חדש.
- אחרי ההדבקה הסוכנות בודקת את החיבור באמת (בדיקת קריאה בלבד) ומראה **"מחובר ✓"** עם שם החשבון.
  אם משהו לא בסדר, היא מראה הסבר פשוט, למשל "המפתח לא נכון או שפג תוקפו".
- **חיבור זה עדיין לא העלאה.** כל פלטפורמה מתחילה במצב אימון. את המתג **"העלאה אמיתית"** באריח מדליקים רק
  כשמוכנים, ואפשר פלטפורמה אחת בכל פעם.
- הממשקים של האתרים משתנים מדי פעם. אם כפתור נקרא קצת אחרת, מחפשים את המילה הכי קרובה.

## 1. יוטיוב, Shorts וטיקטוק דרך Zernio (מומלץ)

**Zernio** (zernio.com) הוא שירות שמעלה בשמך ליוטיוב ולטיקטוק. בתוכנית החינמית אפשר לחבר שני חשבונות,
יוטיוב וטיקטוק. **מפתח אחד מחזיר את שלושת האריחים**: יוטיוב, יוטיוב Shorts וטיקטוק.

למה לא ישירות דרך גוגל? סרטונים שעולים מפרויקט גוגל פרטי שלא עבר אימות ננעלים כפרטיים לתמיד. Zernio עוקף
את זה, וזה הנתיב שהסטודיו כבר הוכיח.

### א. החשבונות ב-Zernio (רק אם עוד לא חיברת)
1. נכנסים ל-https://zernio.com ומתחברים. אם כבר חיברת חשבונות לסטודיו, משתמשים באותו חשבון Zernio.
2. בדשבורד מחברים את **YouTube** (מתחברים עם חשבון הגוגל של הערוץ) ואת **TikTok**.
   אם הם כבר מופיעים ברשימת החשבונות, אין צורך לחבר שוב.

### ב. המפתח
1. ב-Zernio: **Settings** ← **API Keys** ← יוצרים מפתח חדש (Create / New key).
2. מעתיקים את המפתח. לפעמים הוא מוצג פעם אחת בלבד.
3. בלוח הבקרה: **חיבורים** ← האריח **יוטיוב** ← מדביקים בשדה ← שמירה.
   (משורת הפקודה: `agency connect youtube`.)
4. אחרי שנייה מופיע "מחובר ✓" עם שם הערוץ. האריחים של Shorts וטיקטוק נדלקים לבד, אם החשבונות מחוברים ב-Zernio.

### ג. כדאי לדעת
- **טיקטוק דרך Zernio מפרסם לציבור.** אין העלאה פרטית לבדיקה, לכן מדליקים אותו רק כשמוכנים.
  טיקטוק דורש שתאשר בעצמך כל העלאה, ולכן הוא עובד רק במצב "אני מאשר כל העלאה" (ברירת המחדל).
- קליפ עם שוטים של AI מסומן אוטומטית כתוכן שנוצר עם AI, גם ביוטיוב וגם בטיקטוק.
- ביטול פרסום לא מוחק אף פעם: סרטון יוטיוב שכבר עלה הופך לפרטי. את זה עושים דרך חיבור הגוגל, ראו פרק 7.
  בטיקטוק מוחקים ידנית באפליקציה.
- ביטול המפתח: ב-Zernio ← Settings ← API Keys ← מחיקה. בלוח הבקרה: האריח ← **"נתק"**.

## 2. אינסטגרם ופייסבוק דרך האפליקציה שלך במטא

שני האריחים משתמשים ב**מפתח אחד: טוקן עמוד (Page token) שלא פג אף פעם**, מהאפליקציה שלך ב-Meta for Developers.
אם יש לך כבר את האפליקציה של הסטודיו (למשל "Imagination Studio", במצב Live), **לא צריך אפליקציה חדשה.**
מייצרים רק טוקן חדש לפי שלב ג.

### א. החשבונות (פעם אחת)
1. **עמוד פייסבוק** של הערוץ (לא פרופיל אישי). אין? יוצרים כאן: https://www.facebook.com/pages/create
2. **אינסטגרם מקצועי** (יוצר או עסק): באפליקציה ← הגדרות ← סוג חשבון וכלים ← מעבר לחשבון מקצועי.
3. **מקשרים את האינסטגרם לעמוד:** בעמוד הפייסבוק ← הגדרות ← חשבונות מקושרים ← אינסטגרם ← חיבור.

### ב. האפליקציה (רק אם אין לך)
1. https://developers.facebook.com ← **My Apps** ← **Create App** ← סוג **Business**.
2. מוסיפים את **Facebook Login for Business** ואת **Instagram Graph API**.
3. מספיק שאתה מנהל (admin) של האפליקציה. לחשבונות שלך לא צריך App Review.

### ג. טוקן עמוד שלא פג
1. פותחים את **Graph API Explorer**: https://developers.facebook.com/tools/explorer
2. מימין: **Meta App** = האפליקציה שלך. **User or Page** = **Get User Access Token**. מסמנים את ההרשאות:
   `pages_show_list`, `pages_read_engagement`, `pages_manage_posts`, `instagram_basic`,
   `instagram_content_publish`, `business_management`.
   לתגובות ולנתונים אפשר להוסיף גם `instagram_manage_comments`, `instagram_manage_insights` ו-`read_insights`.
3. **Generate Access Token** ← מאשרים את העמוד ואת חשבון האינסטגרם.
4. פותחים את **Access Token Debugger**: https://developers.facebook.com/tools/debug/accesstoken
   מדביקים את הטוקן ← **Debug** ← למטה **Extend Access Token** ← מעתיקים את הטוקן הארוך שמתקבל.
5. חוזרים ל-Explorer, מדביקים את הטוקן הארוך בשדה **Access Token** ומריצים:
   ```
   me/accounts?fields=name,access_token
   ```
   ליד העמוד שלך מופיע `access_token`. **זה הטוקן של העמוד.** אפשר לבדוק אותו ב-Debugger, ושם צריך להופיע
   **Expires: Never**.
6. בלוח הבקרה: **חיבורים** ← האריח **פייסבוק** ← מדביקים ← שמירה. האריח של אינסטגרם נדלק עם אותו מפתח.
   (משורת הפקודה: `agency connect facebook`.)

### ד. המזהים (רק אם האשף מבקש)
אחרי ייבוא מהסטודיו המזהים כבר קיימים. אם לא:
- **מזהה העמוד** (`FB_PAGE_ID`): ה-`id` של העמוד בתוצאה של `me/accounts`.
- **מזהה האינסטגרם** (`IG_USER_ID`): ב-Explorer מריצים `<מזהה העמוד>?fields=instagram_business_account`.
  ה-`id` שבתוך התשובה הוא המזהה.
המזהים הם לא סודות, ולכן הם נשמרים בהגדרות (`meta.page_id`, `meta.ig_user_id`).

### ה. כדאי לדעת
- אינסטגרם יוצא תמיד לפחות 30 דקות אחרי היוטיוב של אותו קליפ. האסטרטג מתזמן את זה לבד.
- בפייסבוק קליפ אנכי של עד 90 שניות עולה כ-Reel, וכל השאר כסרטון רגיל.
- אפליקציה במצב Development עובדת רק לחשבונות שמנהלים אותה. ל"Imagination Studio" זה כבר Live.

## 3. טלגרם: אישורים בלחיצה אחת

לא חובה, אבל נוח: כרטיס עם **"אשר הכל"** מגיע ישר לטלפון. אפשר להשתמש בבוט של הסטודיו
(למשל `@imagination_control_bot`) או בבוט חדש.
1. בטלגרם פותחים את **@BotFather** ← `/mybots` ← בוחרים את הבוט ← **API Token** ← מעתיקים.
   (לבוט חדש: `/newbot`.)
2. בלוח הבקרה: **חיבורים** ← **טלגרם** ← מדביקים ← שמירה ← **צימוד**. מופיע קוד בן 6 ספרות.
3. שולחים לבוט, בצ'אט פרטי: `/start 123456` (עם הקוד שלך). מקבלים אישור, וזהו.
- הבוט מקשיב רק לך, בצ'אט הפרטי שצימדת. כל השאר מתעלמים.
- **אם הסטודיו הישן עדיין רץ** הוא תופס את אותו בוט, ובלוח הבקרה מופיע "הבוט תפוס ע״י הסטודיו הישן".
  עד שהוא נכבה, האישורים נשארים בלוח הבקרה. הסוכנות לא מכבה אותו בעצמה.
- מפתח שדלף: ב-@BotFather ← `/revoke` ← ואז מדביקים את החדש.

## 4. X (טוויטר)

**מפתחות:** `X_API_KEY`, `X_API_SECRET`, `X_ACCESS_TOKEN`, `X_ACCESS_SECRET`
1. https://developer.x.com ← נרשמים עם חשבון ה-X של הערוץ. לחלק מהגישות יש מגבלות, ולפעמים עלות. בודקים לפני.
2. **Projects & Apps** ← יוצרים Project ובתוכו App.
3. **User authentication settings** ← **Set up**: **App permissions = Read and write**,
   Type = Web App, Automated App or Bot. ב-Callback וב-Website אפשר לשים `http://127.0.0.1`.
4. **Keys and tokens**: ב-**Consumer Keys** לוחצים Regenerate (מקבלים API Key ו-Secret), וב-**Access Token
   and Secret** לוחצים Generate. **את ה-Access Token יוצרים אחרי** שההרשאה היא Read and write, אחרת הוא
   יהיה לקריאה בלבד.
5. אשף **X** בלוח הבקרה ← מדביקים את ארבעתם.

## 5. רדיט

**מפתחות:** `REDDIT_CLIENT_ID`, `REDDIT_CLIENT_SECRET`, `REDDIT_USERNAME`, `REDDIT_PASSWORD`
1. מתחברים לרדיט עם החשבון שאיתו תפרסם ← https://www.reddit.com/prefs/apps ← **create another app...**
2. name = `cs2-agency`, סוג **script**, redirect uri = `http://localhost:8080` ← **create app**.
3. ה-client id הוא המחרוזת הקצרה מתחת לשם האפליקציה, וה-secret נמצא בשדה secret. אשף **רדיט** ← מדביקים.
   חשבון עם אימות דו-שלבי לא יכול להתחבר כך.
4. בהגדרות רושמים **בדיוק** לאילו קהילות מותר לפרסם (`subreddits`, בלי `r/`). הסוכנות לא תפרסם לשום מקום אחר.
   קוראים את החוקים של כל קהילה, כי רובן לא אוהבות קידום עצמי. בשבועות הראשונים עדיף להגיב ידנית.

## 6. דיסקורד

**מפתח:** `DISCORD_WEBHOOK_URL` (כתובת Webhook היא סוד)
1. בשרת **שלך**: גלגל השיניים ליד הערוץ ← **Integrations** ← **Webhooks** ← **New Webhook** ← **Copy Webhook URL**.
2. אשף **דיסקורד** ← מדביקים. הבדיקה מראה את שם ה-Webhook.
- קבצים עד 25MB נשלחים כקובץ, וגדולים מזה נשלחים כקישור.

## 7. מתקדם: יוטיוב ישיר דרך Google

**לא מומלץ להעלאות.** סרטונים שעולים מפרויקט Google Cloud שלא עבר אימות **ננעלים כפרטיים**. חיבור גוגל
ישיר שימושי בעיקר לנתונים, לתגובות ולהפיכת סרטון לפרטי. כדי שהסוכנות תעלה ישירות צריך גם לשנות בהגדרות:
`publishing.platforms.youtube.via: direct`. האשף מזהיר מזה.

1. https://console.cloud.google.com ← פרויקט חדש (או הפרויקט של הסטודיו) ← **APIs & Services** ← **Library** ←
   **YouTube Data API v3** ← **Enable**.
2. **OAuth consent screen** (או **Google Auth Platform**): סוג **External**. כדי שהחיבור לא יפוג אחרי 7 ימים,
   מעבירים את האפליקציה ל-**In production**. מסך האזהרה "Google hasn't verified this app" בסדר לשימוש
   אישי: לוחצים Continue.
3. **Credentials** ← **Create Credentials** ← **OAuth client ID** ← **Desktop app** ← **Download JSON**.
4. באשף **יוטיוב** (במצב ישיר): גוררים את קובץ `client_secret….json` ← **"התחבר עם גוגל"**. נפתח דפדפן במחשב,
   בוחרים את חשבון הערוץ ומאשרים. בסוף מופיעים שם הערוץ והתמונה שלו.
   (משורת הפקודה: `agency connect youtube` כשהנתיב ישיר.)
- הקבצים נשמרים ב-`data\secrets\` ולא עולים ל-git. מכסת ה-API היומית מספיקה לבערך 6 העלאות ביום.

## 8. מתקדם: טיקטוק ישיר

רק אם לא משתמשים ב-Zernio (`publishing.platforms.tiktok.via: direct`). **מפתח:** `TIKTOK_ACCESS_TOKEN`.
1. https://developers.tiktok.com ← **Manage apps** ← אפליקציה חדשה עם **Login Kit** ו-**Content Posting API**
   (Direct Post). ה-scopes הם `user.info.basic`, `video.publish` ו-`video.upload`.
2. מקבלים access token בתהליך ההתחברות של Login Kit. הוא פג אחרי כ-24 שעות.
3. **כל עוד האפליקציה לא עברה ביקורת (audit) של טיקטוק, הפוסטים עולים כפרטיים** (`SELF_ONLY`).
   אחרי הביקורת: `privacy_level: PUBLIC_TO_EVERYONE`.

## 9. בדיקה סופית

- עמוד **חיבורים**: כל אריח מראה "מחובר ✓" עם שם החשבון, "לא מחובר" או "צריך תיקון" עם הסיבה.
  אריח שמחובר דרך המפתחות של הסטודיו מראה "מחובר דרך הסטודיו הקיים".
- משורת הפקודה: `agency platforms` (ב-Windows: `.venv\Scripts\agency.exe platforms`).
- כשמוכנים, מדליקים את **"העלאה אמיתית"** בפלטפורמה אחת ומתחילים עם קליפ אחד שאתה שולט בו לגמרי.
  פרטים טכניים על הנתיבים נמצאים ב-[ADVANCED.md](ADVANCED.md).
